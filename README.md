# CokeRoach

I make small open-source tools for problems I run into while making short videos and documents. I also test and report bugs in the tools I use. Outside of code, I'm a big fan of Kurimanju.

## Projects

- **[talk2shorts](https://github.com/CokeRoach/talk2shorts)**: turns a section of a horizontal talk, lecture or interview into a vertical short in one command. The crop follows the speaker, and the captions stay clear of the Shorts, TikTok and Reels buttons. `pip install talk2shorts`
- **[shorts-safezone](https://github.com/CokeRoach/shorts-safezone)**: shows what YouTube Shorts, TikTok and Instagram Reels cover on a 9:16 video, measured from each platform's own templates. [Try it in your browser](https://cokeroach.github.io/shorts-safezone/).
- **[dibs](https://github.com/CokeRoach/dibs)**: checks whether someone is already working on a GitHub issue before you start. It runs as an Agent Skill for contributors and as a [GitHub Action](https://github.com/marketplace/actions/dibs-pr-overlap-check) for maintainers.
- **[docx-fresh](https://github.com/CokeRoach/docx-fresh)**: gives python-docx documents fresh metadata instead of the default template's 2013 values. `pip install docx-fresh`
